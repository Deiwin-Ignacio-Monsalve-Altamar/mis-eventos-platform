# mis-eventos-platform
Full-stack event management application built with Flask, React, PostgreSQL, and Docker, following Clean Architecture and SOLID principles.

## Database and migrations

For local development, create `.env` from `.env.example` only when `.env` does not already exist. Run this from the repository root; it preserves any existing local configuration:

```sh
if [ ! -f .env ]; then
  cp .env.example .env
fi
set -a
. ./.env
set +a
```

The Flask application and Alembic both use `DATABASE_URL`; when it is unset, they use the same local PostgreSQL URL configured by the backend. From the repository root, enter `backend` to run migrations:

```sh
cd backend
poetry run alembic upgrade head
poetry run alembic revision --autogenerate -m "describe schema change"
```

Review autogenerated revisions before applying them. No application models or migration revisions are defined yet.
